# Driver Drowsiness Detection System
Python | OpenCV | Computer Vision | Embedded AI

Real-time driver monitoring system using Python and OpenCV to detect drowsiness via continuous webcam feed analysis.

- Tracks eye closure patterns, blink frequency, and head pose — triggering an audio alert when fatigue exceeds thresholds
- Complete AI pipeline: live video input → feature extraction → classification → actionable output
- Low-latency performance suitable for edge deployment
- Low-cost, camera-based safety system to reduce fatigue-related accidents

### Tech Stack
Python, OpenCV, Dlib, NumPy, SciPy, Pygame

### How it Works
1. Live webcam input
2. Facial landmark detection  
3. Eye Aspect Ratio (EAR) calculation
4. Fatigue detection logic
5. Audio alarm alert
